# Navatha Multi Speciality Dental Hospital

**Dental Clinic Website** - Generated from UI UX Pro Max Design System

## Design
- **Design Family:** Corporate
- **Color Palette:** Trust Blue
- **Location:** Nizamabad, Telangana

## Tech Stack
- Next.js 14
- TypeScript
- Tailwind CSS
- Framer Motion
- Lucide Icons

## Sections
Home, About, Services, Doctors, Technology, Testimonials, Gallery, FAQ, Contact, Google Map, Footer

## Getting Started
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```
